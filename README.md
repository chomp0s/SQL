# 🗄️ University Database & SQL Queries

This repository contains my practical work on relational database design and SQL query optimization. It includes the database schema creation with constraints, populated with test data, and a set of 25 solved tasks covering various SQL concepts.

## 📂 Project Structure

*   **`database_structure.sql`** — Contains DDL (Data Definition Language) statements to create the `university_db` database, tables, and relationships.
*   **`queries.sql`** — A collection of 25 solved practical tasks (DML). It demonstrates filtering, sorting, data aggregation, and working with date/string functions.
*   
*   ## 🚀 How to Run Locally

To test these scripts on your own machine:

1. Open **MySQL Workbench**.
2. Run the `database_structure.sql` script to create the database and populate it with test data.
3. Open the `queries.sql` script, highlight any query you want to test, and execute it (⚡).
